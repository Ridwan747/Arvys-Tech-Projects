Interactive Quiz Application
build a quiz app that asks questions, accepts answers, and calculates scores.
Note : It should have a minimum of 5 questions

Requirements
- Display one question at a time.
- Provide four answer options per question.
- Allow users to select an answer and proceed.
- Show the current question number.
- Calculate the final score.
- Display a result message based on the score.

HOW IT WORKS
Shows one question at a time
Click an option → it highlights
Must select an answer before going next
After 5 questions → shows score and a message (Excellent / Good job / Keep practising)
“Try Again” resets everything
