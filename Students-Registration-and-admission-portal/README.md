Students Registration and admission portal
You are to create a students admission portal with the following requirements

1. Validate name, email, phone number, age, department, and password.
2. Prevent duplicate matriculation numbers or email addresses.
3. Display submitted students in a table.
4. Display the total number of registered students.
5. Show useful error messages beside the relevant inputs.

When done do well to host it on github and then submit per the standard way i showed y'all. Good luck

HOW IT WORKS
Fields: Name, Email, Phone, Age, Matric Number, Department, Password
Error messages appear under each wrong field
Blocks empty fields, invalid email/phone, age outside 15–60, password < 6 characters
Prevents duplicate email or matric number
Shows all registered students in a clean table + total count
