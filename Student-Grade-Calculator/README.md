Student Grade Calculator
Create a function that calculates students scores and grades
Requirements
- Accept a student's name and scores in five subjects.
- Ensure each score is between 0 and 100.
- Calculate the total and average score.
- Assign grades based on predefined score ranges.
- Display the student's result in a table.

Identify the highest-scoring student and the subject with the lowest class average.

HOW IT WORKS
Enter student name + scores for Math, English, Science, History, Art
Each score must be between 0 and 100
Calculates Total, Average, and Grade (A ≥70, B ≥60, C ≥50, D ≥40, F <40)
Shows everything in a table
Also shows:
Highest-scoring student (by average)
Subject with the lowest class average
